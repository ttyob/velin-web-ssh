# 手机 App 开发任务与验收计划

状态：第一版实现与 Android 调试构建已完成，P0 真机验收进行中。日期：2026-10-31。

[需求与技术设计](mobile-app-requirements.md) · [开发指南](development.md)

本计划对应“Flutter 专门手机界面 + 嵌入 xterm.js”。实现集中在 `mobile/`，Go 仅增加兼容的查看订阅、尺寸和输入回执扩展。[构建与使用](../mobile/README.md) · [真实界面截图](../mobile/design/README.md) · [协议 v1](../mobile/contracts/README.md)。

Android 优先验证；iOS 保留工程。本次尚未在真机运行，不将 M0～M3 或 P0 整体标记完成。本机 Docker 服务已在 2026-10-31 更新并验证移动接口；浏览器的 8388 端口仅运行示例数据的设计预览。

| AT-02 | 双击连接、网络慢、指纹未知 / 变化、认证失败 | 一次连接动作对应一个会话；进度可见，失败可退出与重试 |

| AT-04 | 申请接管、拒绝、批准、手机释放或失联 | 控制状态一致；未获控制不发送输入或 resize |
| AT-05 | 中文候选、长文本、Emoji、语音输入、多行正文 | 候选确认不误发送，无重复字符；粘贴与提交语义明确 |
| AT-06 | 连点发送、WS 在写入前后断开、回执丢失 | 不自动重复提交，保留草稿与真实的未确认状态 |
| AT-07 | 同一 input ID 重复、部分写入、去重过期、服务重启 | 只在声明范围内去重；不误报“执行成功” |
| AT-08 | 普通 Shell 与真实 Codex / Claude 的长输出反复滚动 | 按行响应，无历史重复和堆叠，滚动条与位置匹配 |
| AT-09 | 滚动与选择切换、长按复制、点击 TUI 内按钮 | 无误输入、误点击，复制结果与选择一致 |
| AT-10 | 键盘反复开合、切换输入法、旋转屏幕 | 输入和按钮可见；远端网格不随键盘动画抖动 |
| AT-11 | 热重连、WebView 重建、流改变、历史截断 | 正确恢复或说明边界，不把预览重复追加为历史 |
| AT-12 | 锁屏、切应用、Wi-Fi / 移动网络切换、系统回收 | 远端 tmux 继续，回来恢复认证 / 会话与草稿 |
| AT-13 | 中文、空格、引号路径上传，多文件、取消、重试、切会话 | 文件归属准确，偏移检查正确，不落根目录或插错会话 |
| AT-14 | 退出页面、关闭失败标签、终止远端失败 | 离开页面不杀任务；失败记录可重试或移除本地入口 |
| AT-15 | 改手机字号和视图，再回电脑 | 桌面布局、字体与主题偏好不被覆盖 |
| AT-16 | 4 小时真实开发任务、30 分钟交互与高频输出 | 无客户端退出引发的任务终止；界面可响应、内存无持续增长 |
| AT-17 | 预览页面或远端输出尝试访问原生桥 / 登录态 | 不获得终端控制或认证信息，外链按明确流程打开 |
| AT-18 | 手机能力未启用或服务端版本过旧 | 明确显示兼容提示，不通过自动抢权或弱化认证来降级 |

Android / iOS 的模拟器用于布局和自动化检查；系统键盘、剪贴板、生命周期、文件选择与字形验收必须使用对应真机。每条结果标注真实验证范围，不把模拟平台结果记作另一平台通过。

## 8. 验证方式与现有应用回归

按改动选择测试，不为静态页面文案逐项增加镜像实现的测试：

- 契约：消息 schema、错误字段、乱序 / 重复 / 迟到事件、回执与去重边界。
- 后端：新增能力与控制权、尺寸、输入、认证、关闭行为的有效测试。
- 终端：真实 SSH / tmux 与 CLI，复用现有浏览器测试中的有效场景。
- App：关键流程组件测试、平台集成测试与人工真机操作。
- 视觉：关键页面同尺寸截图与设计稿对照，覆盖字体缩放、键盘及异常状态。
- 稳定性：主动切网络、回收进程、限制输出消费速度，记录可复现步骤。

涉及共享代码或后端时，至少运行相关 Go 测试与检查、前端单元检查及生产构建；终端协议或渲染改动还需运行已有 `test:terminal`，并按影响覆盖 Windows 渲染和分数 DPI。只改手机私有页面时不强制重跑无关平台全套检查。

## 9. 模块隔离与移除

1. 手机客户端、xterm 资源与移动契约集中在 `mobile/`，业务代码不依赖 `WorkspaceView.vue`。
2. Go 扩展集中在移动专用文件和单独注册入口；公共协议只做兼容扩展，不改变旧消息默认语义。
3. 首版尽量不新增持久数据库表；需要迁移时单独记录 schema、迁移和回退条件。
4. App 设置、草稿和缓存独立命名，不占用或覆写 Web 布局文档。
5. 移除时删除移动目录、扩展注册、专用构建流程和文档入口，清理明确列出的扩展字段；原账户、主机、凭据与 tmux 会话保留。
6. 移除后运行现有 Go / Web 构建与受影响终端回归，确认 Docker / fnOS / Windows 仍可独立发布。
